BoxIPTV Pro

Guia Definitivo: Desenvolvimento, Deploy na VPS e Geração de APK

1 Rodar o Projeto em Localhost

Para testar novas funcionalidades no seu computador antes de enviar para o servidor, precisa de iniciar o Backend (API) e o Frontend (React).

Passo A: Iniciar o Backend (FastAPI)

# 1. Navegue até à pasta do backend
cd backend

# 2. Ative o ambiente virtual Python
venv\Scripts\activate

# 3. Inicie o servidor
python main.py

O backend ficará a rodar em http://localhost:8006.

Passo B: Iniciar o Frontend (Vite/React)

No seu projeto, utiliza o script de gestão de ambientes para direcionar a API.

# 1. Abra um novo terminal e vá para a raiz do projeto
# 2. Rode o script de mudança de ambiente
python mudar_ambiente.py

# 3. Escolha a Opção 1 (Localhost)
# 4. Entre na pasta do frontend e inicie
cd frontend
npm run dev

O frontend ficará disponível em http://localhost:3006.

2 Deploy Automático na VPS

Sempre que as atualizações estiverem perfeitas, é hora de enviar para a nuvem.

Passo A: Enviar para o GitHub

# Na sua máquina local, rode:
git add .
git commit -m "Nova atualização incrível"
git push origin main

Passo B: Atualizar o Servidor

Graças ao seu script deploy.sh, o processo na VPS é extremamente simples.

# 1. Aceda ao seu servidor via SSH e vá para a pasta do projeto
cd /var/www/boxIPTV

# 2. Puxe o código mais recente do GitHub
git pull

# 3. Execute o script de Deploy
chmod +x deploy.sh ➔ ./deploy.sh
Nota: O script encarrega-se de compilar o Vite, gerar a pasta dist e reiniciar o Nginx e o FastAPI automaticamente. O seu site web estará imediatamente atualizado.

3 Gerar o Ficheiro APK (Android)

Para construir a aplicação que será instalada nos telemóveis e TV Boxes, o código React precisa de ser empacotado pelo Capacitor e compilado no Android Studio.

  1. Mudar o Ambiente: O APK não pode apontar para o localhost. 
    python mudar_ambiente.py
# Escolha a Opção 2 (APP Android / Domínio)
  2. Compilar o Frontend para Produção: 
    cd frontend
npm run build
  3. Sincronizar com o Capacitor: Isto copia os ficheiros HTML/JS gerados para dentro da pasta nativa do Android. 
    npx cap sync android
  4. Abrir no Android Studio e Gerar: 
    npx cap open android

    No Android Studio, aguarde o carregamento completo (índice e Gradle). Depois, no menu superior, clique em:
    2x Shift ➔ Digite Clean e limpe ➔ Digite APKs e gere o APK

Sucesso! Quando a compilação terminar, clique em "locate" na notificação do canto inferior direito. O ficheiro app-debug.apk estará pronto para ser instalado.
